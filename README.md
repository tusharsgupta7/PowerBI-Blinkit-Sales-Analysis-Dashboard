# 📊 Blinkit Sales Analysis Dashboard — Power BI

## 📊 Dashboard Visualization

The dashboard provides an interactive analysis of Blinkit's sales performance, outlet performance, item categories, fat content, outlet size, outlet location, and key business KPIs.

---

## 📌 **Project Overview**

This Power BI project is an interactive **Blinkit Sales Analysis Dashboard** designed to analyze sales performance, customer ratings, item distribution, and outlet characteristics.

The dashboard uses key performance indicators and multiple visualizations to understand how **fat content, item type, outlet size, outlet location, outlet establishment, and outlet type** affect overall sales performance.

The business requirement focuses on analyzing **sales performance, customer satisfaction, and inventory distribution** using KPIs and interactive visualizations in Power BI.
